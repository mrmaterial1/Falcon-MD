## 🦅 What is Falcon-MD?

**Falcon-MD** is a powerful, fast and lightweight WhatsApp Multi-Device bot built with **Baileys** and **Node.js**. It comes loaded with PM controls, group management, games, downloaders and much more — all in one bot!

---

## ✨ Features

<div align="center">

| PM Control | Group Control |
|-----------|--------------|
| 🌙 AFK System | 👋 Welcome/Goodbye |

## 📱 Commands

<details>
<summary><b>⚙️ PM Control Commands</b></summary>
.afk on | off          - AFK mode
.afk msg         - Set AFK message
.online on | off       - Always online
.anticall on | off     - Block calls
.dlt on | off          - AntiDelete
.ae on | off           - AntiEdit
.ping                  - Check speed
.alive                 - Bot status
.sudo add         - Add sudo user
.tts       - Text to speech
.weather     - Get weather
.time        - Get time
.play            - Play music
.dla              - Download media
.rd on | off           - Auto read
.reboot                - Restart bot
</details>

<details>
<summary><b>👥 Group Control Commands</b></summary>
.welcome on | off      - Welcome message
.atl enable | disable  - AntiLink
.warn @user            - Warn user
.unwarn @user          - Remove warn
.kick @user            - Kick user
.kickall               - Kick everyone
.promote @user         - Make admin
.demote @user          - Remove admin
.mute | .unmute        - Mute group
.tag             - Tag all members
.filter       - Add filter
.spam on | off         - AntiSpam
.sched HH:MM     - Schedule message
</details>
