## 🦅 What is Falcon-MD?

**Falcon-MD** is a powerful, fast and lightweight WhatsApp Multi-Device bot built with **Baileys** and **Node.js**. Loaded with PM controls, group management, games, downloaders and much more!

---

## 📱 Commands

<details>
<summary><b>⚙️ PM Control Commands</b></summary>

| Command | Description |
|---------|-------------|
| .afk on / off | AFK mode |
| .afk msg text | Set AFK message |
| .online on / off | Always online |
| .anticall on / off | Block calls |
| .dlt on / off | AntiDelete |
| .ae on / off | AntiEdit |
| .ping | Check speed |
| .alive | Bot status |
| .sudo add jid | Add sudo user |
| .tts lang text | Text to speech |
| .weather location | Get weather |
| .time timezone | Get time |
| .play song | Play music |
| .dla url | Download media |
| .rd on / off | Auto read |
| .reboot | Restart bot |

</details>

<details>
<summary><b>👥 Group Control Commands</b></summary>

| Command | Description |
|---------|-------------|
| .welcome on / off | Welcome message |
| .atl enable / disable | AntiLink |
| .warn @user | Warn user |
| .unwarn @user | Remove warn |
| .kick @user | Kick user |
| .kickall | Kick everyone |
| .promote @user | Make admin |
| .demote @user | Remove admin |
| .mute / .unmute | Mute group |
| .tag text | Tag all members |
| .filter trigger | Add filter |
| .spam on / off | AntiSpam |
| .sched HH:MM text | Schedule message |

</details>

## 🛠️ Local Setup Termux

**Step 1 - Clone the repo**

git clone https://github.com/mrmaterial1/Falcon-MD

**Step 2 - Enter the folder**

cd Falcon-MD

**Step 3 - Install dependencies**

npm install

**Step 4 - Generate session**

npm run session

**Step 5 - Start the bot**

npm start
